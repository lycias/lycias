### LA-PrEP Africa CEA — Independent Cost-Effectiveness Analysis

**Python · Monte Carlo Simulation · Health Economics** | 🔒 _Private (under NDA)_

Independent replication and probabilistic sensitivity analysis of a cost-effectiveness model for long-acting PrEP in sub-Saharan Africa. Built a 3,000-run Monte Carlo simulation to quantify uncertainty and identify key model drivers.

**Technical highlights:**

* Probabilistic sensitivity analysis (PSA) with variance decomposition

* Interactive dashboards using Plotly and ipywidgets

* Threshold and tornado analysis for parameter sensitivity

* Python stack: NumPy, SciPy, Pandas, Google Colab

**Results:** Central CE ratio 4.91× GiveWell benchmark (95% CI: 2.6×–10.8×); identified incidence variation as explaining \~17% of total uncertainty; break-even threshold at 0.45% incidence.
